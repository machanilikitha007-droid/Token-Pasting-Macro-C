# Token Pasting Macro in C

A simple C program that demonstrates the token pasting operator (##)
used in preprocessor macros to combine two tokens.

## File

token_pasting.c

## How to Run

gcc token_pasting.c -o token_pasting
./token_pasting

## Sample Output

Token Pasting Example
number1 = 10
number2 = 20
number3 = 30

## Concept Used

- Preprocessor Macro
- Token Pasting Operator (##)
